**Live site:** https://YOUR-USERNAME.github.io

## Sections
- **Summarizing statement** – hero with headline, call-to-action buttons and quick facts
- **About** – short professional story plus interests
- **Education** – timeline of programs at Mohawk College
- **Skills** – technical skill cards and soft skills backed by examples
- **Projects** – filterable project cards written as Problem → Approach → Learned, plus a working **HelpDesk Lite** ticket-tracker demo
- **Resume** – experience highlights and a downloadable PDF
- **Contact** – spam-protected email, LinkedIn, GitHub and a mailto contact form

## Built with
- Semantic HTML5
- CSS3 (custom properties, Grid, Flexbox, light/dark themes, responsive breakpoints)
- Vanilla JavaScript (IntersectionObserver, event delegation, localStorage)
- Hosted on GitHub Pages — no frameworks or build step
